Birthday Card App
COP4656

We created a birthday card app with a gradient background, 
centered text, and added a red border to make it look festive.

Gradient background was done using colors yellow and red through
Brush.linearGradient() function

Text alignment was dine using imported compose features

The rest was put together using this tutorial:
https://developer.android.com/courses/pathways/android-basics-compose-unit-1-pathway-3?authuser=1#codelab-https://developer.android.com/codelabs/basic-android-kotlin-compose-text-composables
